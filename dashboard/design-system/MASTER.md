# AI-Lab — Context, considered

## Purpose
An independent research workspace for evaluating agent governance. Lead with understandable comparisons; make evidence one click away. Never turn missing, simulated, or fixture data into measured claims.

## Tokens
- Canvas `#F5F6FA`; paper `#FFFFFF`; ink `#192238`; night `#182137`; iris `#6955D8`; sea `#167A68`.
- Display: Bricolage Grotesque, weight 500–700. Body: Manrope, weight 400–700. Data: IBM Plex Mono, tabular numerals.
- Spacing: 4/8/12/16/24/32/48/64 px. Corners: 10 px controls, 18 px panels, 24 px hero.
- One restrained shadow, solid surfaces, visible borders. No decorative glass, glows, or emoji icons.

## Obsidian Violet dark theme
- Canvas `#131116`; sidebar/top chrome `#1B1820`; cards `#24202B`; hero `#2B2439`; borders `#40364B`.
- Primary violet `#A78BFA`; action background `#7355D3`; primary text `#F2EFF5`; muted text `#B8AFBF`; verified/success accent `#67D2AE`.
- Keep ordinary cards neutral. Violet identifies actions, selection, the context diagram, and governed data. Mint carries meaningful evidence or success information.
- Initial theme follows the system. Explicit toggle choice persists under `ai-lab.theme.v1`; bootstrap applies it before styles paint. Theme metadata follows the active canvas.

## Provider and evidence treatment
Provider marks are local first-party assets. Transparent Google and monochrome OpenAI/Anthropic artwork remain legible on canvas-colored dark plates. Native model selection stays keyboard accessible; adjacent identity and comparison rows show the provider.

Labels use small angular outlines rather than colored pills. Snapshot/open-source markers use meaningful icons rather than decorative dots. Verified ledger records show a mint shield and text. Ledger identity uses one icon next to a stacked experiment/model label; numeric columns align right.

## Motion
Use 220ms ease-out page entrances, bounded 30ms row staggering, 0.97 press feedback, 200ms drawer entrance, 180ms details reveal, and a brief confirmation pulse. Native theme crossfade is optional and permits pointer input. Avoid bounce and ambient motion. Reduced motion disables animation, delays, transitions, and active-state transforms.

## Identity
Orbit mark: context organized around a clear center. Hero orbit labels the real five-stage ICM pipeline. This is the single expressive visual; surrounding interface stays quiet.

## Navigation and behavior
Overview, Experiments, Model simulator, Sandboxes, Evidence ledger. Hash links preserve browser history and deep linking under GitHub Pages. Mobile menu offers identical destinations, Escape dismissal, and restored focus.

Measured data, demo fixtures, and pricing projections have distinct written labels. Original snapshot metadata accompanies JSON export. Model selection affects simulator only. Report freshness means snapshot generation time, not a live connection.

## Accessibility
Body text 16 px; secondary labels at least 12 px. Controls at least 44 px tall. Visible focus, skip link, labeled fields, semantic regions/tables, text alternatives for graphics, reduced-motion support, no page-level horizontal overflow. Dense evidence tables scroll within labeled regions.
