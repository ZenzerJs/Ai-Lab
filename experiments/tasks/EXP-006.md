# EXP-006: Concurrency-Safe Transactional Ledger with Real-Time Dashboard & E2E Validation

Build a high-reliability financial transactional ledger with concurrency invariant guarantees, an accessible live Tailwind dashboard, and Playwright verification test suite.

Requirements:
1. Backend Transaction Engine:
   - Implement concurrency-safe double-entry ledger with balance invariants.
   - Enforce idempotency keys and prevent race conditions / double-spending under concurrent mutations.
2. Frontend Interface:
   - Modern Tailwind CSS dark-mode dashboard displaying live ledger balance, transaction history, and account metrics.
   - Micro-interactions, optimistic UI updates, and explicit error states.
3. Automated QA & Verification:
   - End-to-end Playwright headless test assertions verifying balance integrity, optimistic updates, and concurrent transaction handling.
