# EXP-005: Full-Stack Marketing Landing Page

Build a complete, responsive landing page for an API analytics SaaS named "PulseEngine".

Requirements:
1. Modern sticky navbar with logo, 3 navigation links, and a "Get Started" primary button.
2. Hero section with bold value prop, subheading, dual CTA buttons, and social proof metric badges.
3. Feature grid with 3 cards showcasing core capabilities (clean SVG icons, borders, micro-interactions).
4. Interactive Monthly / Annual pricing switch showing two plan tiers ($29/mo and $99/mo with 20% annual discount applied via vanilla JavaScript).
5. Clean minimalist footer with links and copyright.
6. Fully responsive across mobile (375px) and desktop (1440px).

Output constraints: Standalone `index.html` file utilizing Tailwind CSS CDN.
