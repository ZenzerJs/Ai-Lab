# EXP-009: Multi-Tenant Event-Driven Job Queue & Observability UI

Build a production-grade, multi-tenant event-driven job queue engine with DAG dependency scheduling, resilient worker execution, dead-letter retries, and an accessible live queue monitor dashboard.

## Target Architecture (7 Files)
1. `queue_engine/schema.py`: Job, Tenant, Event, Priority definition, and JobState enums with dataclass serialization.
2. `queue_engine/storage.py`: In-memory and SQLite-backed persistent queue store with multi-tenant isolation and atomic state transitions.
3. `queue_engine/dag.py`: Directed Acyclic Graph dependency resolver with cycle detection, multi-root resolution, and topological execution ordering.
4. `queue_engine/worker.py`: Concurrent worker pool with lease-based claiming, heartbeats, cooperative cancellation, and progress reporting.
5. `queue_engine/retry.py`: Exponential backoff with jitter and dead-letter queue (DLQ) threshold routing.
6. `queue_engine/ui.html`: Standalone responsive queue observability interface with accessible status indicators, latency sparklines, and zero horizontal overflow.
7. `tests/test_exp009.py`: Deterministic test suite verifying dependency resolution, worker leasing under concurrency, and dead-letter routing.

## Planted Defects & Edge Cases to Fix
- **DAG Cycle Detection**: Resolver exhibits false negative when detecting cycles across multi-root detached graphs.
- **Worker Race Condition**: Concurrency hole in unacknowledged lease acquisition allows duplicate workers to process the same job.
- **Thundering Herd**: Exponential backoff missing jitter causes synchronized retry bursts on shared storage.

- **1. Correctness (0–5)**: All pytest assertions pass (DAG ordering, atomic leasing, retry backoff).
