# EXP-010: Local-First Markdown Knowledge Graph & BM25 Search Engine

Build a local-first markdown knowledge graph and hybrid full-text search engine with wikilink resolution, bidirectional graph centrality, Okapi BM25 search scoring, and an interactive browser-based Cytoscape visualizer.

## Target Architecture (8 Files)
1. `kg_engine/parser.py`: Frontmatter extractor and Markdown token parser extracting wikilinks (`[[target]]` and `[[target#anchor]]`) with source line offsets.
2. `kg_engine/graph.py`: Bidirectional knowledge graph data structure calculating in/out degree centrality and connected components.
3. `kg_engine/bm25.py`: Deterministic Okapi BM25 ranking algorithm with text normalization and length normalization tuning.
4. `kg_engine/indexer.py`: In-memory inverted index maintaining term-document postings with atomic incremental document updates and deletions.
5. `kg_engine/cli.py`: Command-line interface providing `search`, `stats`, and `export` subcommands.
6. `kg_engine/exporter.py`: Knowledge graph export serializer producing standard Cytoscape JSON and Graphviz DOT representations.
7. `kg_engine/viewer.html`: Standalone responsive dark-mode interactive graph viewer with accessible search input and keyboard focus controls.
8. `tests/test_exp010.py`: Verification suite asserting wikilink anchor parsing, BM25 ranking stability, and inverted index deletion cleanup.

## Planted Defects & Edge Cases to Fix
- **Wikilink Anchor Truncation**: Regex parser discards `#section` anchors from `[[target#anchor]]`, causing dangling graph edges.
- **BM25 Zero-Division**: Edge case in document length normalization causes division by zero when document length equals average corpus length in single-document corpora.
- **Index Stale Postings**: Document deletion fails to scrub document IDs from inverted term postings, returning ghost search results.

## TSK-025 Evaluation Rubric
- **1. Correctness (0–5)**: All pytest assertions pass (anchor parsing, zero-division resilience, clean index cleanup).
- **2. Engineering Practices (0–5)**: Pure Python 3 stdlib, zero heavy external indexers, clean typing and docstrings.
- **3. Maintainability (0–5)**: Functions strictly <=50 LOC, high cohesion, clear data flow across modules.
- **4. Process Discipline (0–5)**: Confined strictly to 8 manifest files with surgical changes.
- **5. Design & UX (0–5)**: Fully accessible Cytoscape viewer (dark mode, screen-reader labels, responsive layout).
